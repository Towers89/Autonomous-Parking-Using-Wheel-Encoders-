# Autonomous Parking Using Wheel Encoders

## Project Overview
This project focuses on the design and implementation of an autonomous parking system that operates without the use of external sensors such as ultrasonic or infrared modules. Instead, the system relies entirely on wheel encoders to estimate displacement by counting the number of pulses generated as the wheels rotate. By converting encoder ticks into distance measurements, the robot is able to determine how far it has traveled and use this information to precisely control its motion.

The system is implemented on the MSP432 microcontroller and deployed on the TI-RSLK MAX robotics platform. Motor control is achieved through a motor driver interface, allowing the robot to execute controlled forward, reverse, and turning movements. The overall goal of the project is to demonstrate that accurate and repeatable autonomous parking can be achieved using only internal feedback mechanisms, without relying on environmental sensing.

## System Architecture
The control logic of the system is structured around a finite state machine (FSM), which organizes the parking process into a sequence of well-defined states. Each state corresponds to a specific motion of the robot, such as reversing out, turning into the parking spot, or straightening the vehicle once aligned. This modular approach allows each movement to be independently controlled and verified, improving both clarity and reliability of the system.

State transitions are governed by encoder feedback rather than time-based delays. As the robot moves, encoder pulses are continuously counted using hardware interrupts, and the accumulated tick count is compared against predefined thresholds that represent target distances. Once the required number of ticks has been reached, the system transitions to the next state in the sequence. This ensures that the robot’s movements are based on actual displacement rather than assumptions about speed or timing, which significantly improves accuracy.

The FSM includes states such as initialization, reversing, turning into the parking position, reversing further into the space, straightening the wheels, and final positioning. By structuring the system in this way, the complexity of autonomous control is reduced, and the behavior of the robot becomes easier to debug and refine.

## Interfaces and Peripherals Used
The implementation makes extensive use of the MSP432’s onboard peripherals to interface with the robot’s hardware components. General-purpose input/output (GPIO) pins are configured to read the digital signals generated by the wheel encoders. These signals are processed using interrupts, allowing the system to increment encoder counts in real time without missing pulses, even at higher wheel speeds.

Timer_A is configured to generate pulse-width modulation (PWM) signals, which are used to control the speed of the motors. By adjusting the duty cycle of the PWM signals, the system can regulate motor speed and ensure smooth and consistent movement during each phase of the parking sequence. The motor driver acts as an interface between the microcontroller and the motors, translating the control signals into the appropriate voltage and current required for operation.

Only one channel of each encoder is used to count pulses for distance estimation. While this approach does not capture direction information inherently, direction is instead controlled through motor commands issued by the FSM. Specific MSP432 pins are assigned to motor direction control, motor enable signals, and encoder inputs, ensuring a clear mapping between software control and hardware functionality.

## Verification and Testing
A structured verification and testing process was followed to ensure the correctness and reliability of the system. Initially, each hardware component was tested independently to confirm proper operation. Encoder functionality was verified by monitoring pulse counts through UART output, allowing real-time observation of tick accumulation as the wheels rotated.

After validating individual components, the FSM was implemented incrementally, with each state tested in isolation before integrating the full sequence. This approach made it easier to identify and correct issues related to state transitions and movement accuracy. The distance traveled by the robot was measured and compared against expected values derived from encoder tick counts, revealing discrepancies that were addressed through calibration.

Encoder tick thresholds for each movement were iteratively adjusted to account for factors such as wheel slip, surface variation, and mechanical tolerances. Through repeated testing and refinement, the system achieved consistent and reliable performance, with the robot successfully executing the complete parking maneuver.

## Project Demonstration
The final system demonstrates the robot performing an autonomous parking sequence using only encoder-based feedback. The robot begins from an initial position, reverses to create space, turns into the parking spot, adjusts its position, and completes the maneuver without any external sensing input. The demonstration highlights the effectiveness of encoder-based control and the robustness of the FSM design.

## Conclusion
This project successfully demonstrates that autonomous parking can be achieved using only wheel encoder feedback and motor control, without the need for additional sensors. By leveraging encoder data and a finite state machine architecture, the system is able to execute precise and repeatable movements that result in accurate parking behavior.

One of the key challenges encountered during development was the attempted use of an infrared sensor, which produced inconsistent analog-to-digital conversion readings and introduced unreliability into the system. As a result, the design was revised to eliminate dependence on the IR sensor and instead rely entirely on encoder-based feedback. This change simplified the system and improved overall performance.

The final implementation highlights the importance of feedback-driven control in embedded systems and demonstrates how relatively simple hardware can be used to achieve complex autonomous behavior when combined with well-structured software design.
